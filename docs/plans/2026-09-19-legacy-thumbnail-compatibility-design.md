# 旧项目截图兼容修复

## 问题

中央缩略图端点优先读取 `thumbnail.webp`。旧项目通常只有 `thumbnail.png`；当前实现发现旧 PNG 后仅在后台请求截图服务转为 WebP，并在转换完成前返回 SVG 占位图。截图服务限流或转换失败时，旧截图仍安全保存在 R2，却永远不会展示。

## 决策

保持 WebP 为长期首选格式。若 WebP 尚不存在但 R2 中存在有效旧截图，中央端点立即返回旧截图，同时在后台继续生成 WebP。旧截图使用 60 秒短缓存，不写入 Cache API；生成成功后后续请求会自动切换到长期缓存的 WebP。只有旧截图和 WebP 都不存在时才返回彩色 SVG 占位图。

这个方案不修改或删除任何 R2 对象，不依赖批量迁移完成，也不会因为截图服务限流而让已有截图消失。

## 验收标准

- 已有 PNG、没有 WebP 时，中央端点立即返回 PNG 和原始字节数。
- 后台 WebP 生成失败时，PNG 仍正常显示。
- 已有 WebP 时继续优先返回 WebP 和长期缓存。
- 两种图片都缺失时继续返回项目专属 SVG 占位图。
- lint、type check、专项测试、生产构建和 Worker dry-run 全部通过。
