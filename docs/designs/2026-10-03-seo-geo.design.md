# SEO / GEO 与获客指标

## 来源与范围

用户原话「seo 优化。并且最好拥有指标」，确认重点「搜索带来的访问和注册」，追加「geo 也要优化」。按 GEO 为生成式搜索/问答的可发现与可引用性处理；不改变尚在探索的定位。当前能力沿实际 HTML/ZIP/GitHub 发布路径说明。standard / feature，跨 Pages、browser、analytics contract、API、admin，L3；授权内生产发布 L4。plan: not-required，单批闭环。retrospective_state: pending。

## 事实与方案

现有 SPA 所有路由复用首页 canonical；robots 引用不存在的 XML sitemap（线上返回首页 HTML）；OG 图片路径返回 HTML；JSON-LD 含无来源评分。产品事件已有匿名 visitor/session、搜索来源、UTM 和 server signup，但只有邮箱，并会把已有 OAuth 账号加密码算成注册。后台与生产流量已有权威，不另建分析数据库。

候选：只补 meta 会保留空 body、错误路由和注册缺口；全站 SSR 重写耦合管理与用户数据，成本过高；选 Pages 原响应 HTMLRewriter + 共享公开内容/metadata，以及现有 product_events 的独立只读获客投影。每个访问者得到同一 HTML，不按 UA 返回不同内容。公开内容单一 owner `frontend/seo.mjs` 被构建、Pages 和 React 消费。保留 app 登录/管理主链路；删除无来源评分、失效图片引用和全路由首页 canonical。暂不改用户应用托管及动态作者索引。

- 首页/探索、about、HTML/ZIP 指南提供 English / zh-CN 可寻址版本，self canonical + 双向 hreflang。显式 lang 优先；页面语言选择和 URL 同步。指南从可见页面互链并进入 sitemap；未知 HTML 路径 404/noindex；真实管理、登录、作者、legal 页面继续可用且 noindex，不泄露私人数据。原 API 代理与流式响应保留。
- 指南直接回答发布任务，说明步骤、静态/有构建 ZIP 差异、失败处理、公开访问与内容边界。真实 Organization / WebSite / WebPage / Article JSON-LD 与可见内容一致，不承诺 rich result 或引用；llms.txt 仅补充事实入口，不声称标准或提升排名机制。
- 匿名首入 referrer 保存到现有 sessionStorage，搜索扩充常见引擎、AI 域名严格边界识别（含 ChatGPT / Perplexity / Claude / Gemini / Copilot）；剔除带付费 medium 的搜索。新增 ai 变体在 producer、parseBatch、D1 文本字段、report/UI 顺序部署并测试。guide 页面归类，绝不上传搜索词或原始 URL。
- signup_success 只对应真正创建账号。邮箱成功响应标明是否新账号；OAuth start 携带只有匿名 IDs/枚举/UTM 的空事件 context，经现有短期 HttpOnly OAuth state cookie 绑定并在有效回调创建账号后由 API server 记录。重登与加密码不算注册。关闭采集/DNT/无合法 context 不收集。验证 callback 成功状态与内部 server 标记；失败不改变认证。不会改变账户或 OAuth 权限。
- 新注册使用 server event 的 email/google/github 维度区别历史口径；首次生产部署后在现有 analytics_settings 写一次 acquisition_registration_start（真实启用时间），无配置时不造起点。之前日期注册显示不可用，率的分母仅启用后 cohort；部署升级保留原起点。此补充沿原测量目标，受影响设计Review复核通过。
- admin「搜索与 AI 获客」：近7/30完整UTC日、search / ai 的去重访问浏览器、入口会话、同窗口有序新注册会话、注册事件与转化率、每日趋势、按入口页面类别和来源的明细、CSV。同一 session 首个 page_view 形成 cohort，仅 signup at>=入口且在窗口中计入，零分母率 null；不把登录/点击视为注册。D1内聚合、现有reserve预算、15min cache、无自动轮询。30天raw明细滚动边界不完整日置不可用，不能补零或相加UV；覆盖范围公开。
- Search Console 展示/点击/CTR/排名与索引是外部权威。检查已登录可用属性；无法接入明确未连接及官方入口，不造数据。AI 引荐不等于 AI 引用次数；Google AI流量不能从常规 Google来源分开。

## 黄金验收与必要矩阵

1. 新访客/爬虫 → 打开首页或指南（含zh-CN）→ 无JS读到同一可见任务说明、canonical与links → 跳发布入口 → 现有发布链路可用。raw HTML、实际Pages runtime及React导航/移动端检查；资源保持真实类型，未知路径404；API代理流式回归。
2. 已授权管理员 → 原后台登录 → 搜索与AI获客 → 切换7/30日 → 查看有序注册转化、覆盖缺口与空态 → 导出相同daily CSV。D1 fixture覆盖错序、重复事件、多session、其他来源、付费搜索、后台/非web、零分母和留存缺口，SQL真实SQLite执行；生产只读基线对账。
3. 搜索/AI访客 → 页面 → 邮箱新建或有效OAuth新建 → signup_success同匿名context → admin可见。API组装回归验证邮箱新建/加密码、OAuth新建/已有/失败、DNT及关闭采集，事件不改变业务返回。测试不会建立线上测试客户。
