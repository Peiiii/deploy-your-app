# 首页底部发布帮助展示

用户于 2026-10-03 提供首页底部截图，要求改善展示。现状：`PublicInfo` 调用 `frontend/seo.mjs` 的共享正文，三段长文本和一排紫色下划线链接缺少层级，政策链接与首页页脚重复。

## 方案与范围

采用 standard、小范围视觉改动（L1）。比较保留正文仅调整字号、轻量分栏帮助面板、折叠 FAQ：选择分栏面板，能直接扫读且无需额外点击；只调字号不足以改善信息层级，折叠增加交互且隐藏正文。首页桌面三栏，小屏及预览挤窄时按实际可用宽度回到单栏。探索页复用同一支持区域样式，但保留其一段说明。

内容继续由 `frontend/seo.mjs` 唯一维护，`includeHeading=false` 的首页/探索页使用帮助面板：小标题、说明分栏、发布/探索行动入口、分隔后的次要导航。指南/关于及无 JavaScript 原始 HTML 保持完整标题、说明、全部导航和政策入口。首页帮助面板去掉重复政策链接，首页既有页脚保留；探索页没有政策页脚，保留政策入口。CSS 在已有 `frontend/index.html` 中使用现有主题 token，不新建组件、状态或渲染路径。沿用文案事实及真实 `a href`，不改变部署、公开展示语义或 SEO metadata。

## 验收路径

- 从首页浏览应用后滚动到底部：说明形成三栏，发布按钮突出，次要导航易辨；点击发布进入已有 `/deploy`，返回后指南链接进入对应指南。
- 在手机、侧边预览挤窄、英文和深色主题下滚动到底部：面板自然纵排，文字可读、链接可聚焦、无水平溢出。探索页单段说明不留下空列。
- 指南与原始 HTML：标题/正文与原有真实链接仍可读取；SEO Pages 组装回归通过。
