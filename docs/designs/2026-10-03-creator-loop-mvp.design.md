# 创作者使用反馈闭环 MVP

状态：active；2026-10-03；flow=standard，task-type=feature，风险 L3（交付 L4）。

## 目标与选择

用户要求把方向讨论做成能体验的 MVP，并询问推荐。推荐并执行现有 GemiGo 的真实作品闭环：作者发布/编辑介绍、分享公开作品页，使用者在线体验、收藏、评论，作者在项目设置查看和回复反馈，再结合已有 PV/UV 改进。生产端优先不预设向生产者收费；不默认 AI Studio 来源。方向依据：`docs/thoughts/2026-10-03-app-deployment-direction.thought.md`。

候选：仅扩展预览（无法形成独立分享入口，移动端直接跳应用）；新增作品页并复用既有能力（选择）；全新商城/演示购买（主体、收款资格与分账模式未确定，不能作为实际成交证据）。真实支付、自动创作和官方示范应用未纳入本版，不将收藏或评论解释为付费需求验证。

## 实际使用链路

1. 作者在项目设置的常规页编辑名称、介绍、分类等，沿用现有保存机制；项目公开且 Live 后，进入新增“分享与反馈”标签，复制作品页链接。私有或未上线项目显示不可分享原因。
2. 使用者在新窗口打开 `/app/:id`，无需登录看到名称、介绍、分类、作者入口；点击“开始体验”嵌入现有应用，也可新窗口打开。首页/探索卡片保留预览，增加作品页入口。
3. 收藏/点赞要求登录；评论沿用现有登录、500 字限制、分页、回复、删除权限及失败重试。反馈只在作品成功加载后请求；失败不显示为已提交。
4. 作者进入项目的“分享与反馈”，看到同一评论记录并回复；进入已有数据标签查看 7/30 天 PV/UV 等。反馈与统计不创建第二套存储。
5. 手机窄屏采用上下布局，说明和反馈可滚动访问；刷新/直接链接可恢复作品页。作品不存在、私有、下线或删除时不给出内容，网络失败可重试。

## Owner 与实现

- API：ExploreService 新增单件公开读取，`GET /api/v1/apps/:id`。公开条件复用 Project 语义：未删除、isPublic 不是 false（兼容旧行）、Live、有合法 http(s) URL。返回显式白名单展示 DTO，不返回 repoUrl、HTML、analysisId、providerUrl 等源数据。作者先经过 publicAuthorService 解析，再取公开身份。
- 前端：现有功能目录新增 app-detail，manager 持有加载状态、AbortController 与请求代次，防止切换作品后旧请求覆盖；页面仅编排展示与 UI 状态。复用 AppPreviewContent、reaction manager/store、PreviewCommentsPanel、剪贴板和现有作者身份。
- 评论面板的关闭回调变为可选，嵌入页不显示关闭按钮；旧预览保持既有行为。作者入口只在 owner 设置页面中，仍沿用既有权限。
- 分享链接稳定使用项目 id。介绍从现有项目 metadata 读取，新增类别、定价和描述字段不另建。首次访问关闭旧预览侧栏，避免遮挡。中文/英文完整文案，其它语言沿用项目既有回退。
- 本版路由依赖现有 SPA 回退；页面默认 SEO 合同沿用当前动态路由 noindex，暂不承诺搜索抓取或动态分享卡片。
