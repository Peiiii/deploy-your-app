# AI写好的网页，怎么发给别人用？

AI 写了个网页，想发给朋友看看，结果地址还是 localhost:5173。

这个地址只在自己电脑上能用。要让朋友点开，需要把网页部署出去，拿到一个公开链接。

如果 AI 给的是完整 HTML，可以直接粘贴；拿到的是 ZIP，就上传压缩包。GitHub 放在后面讲，没用过也不用为了这一步专门去学。

不确定自己拿到的是哪种文件，就把项目交给 AI，问它怎么打包、要不要构建。图里放了可以直接问的话，工具和网址在第 3 张。

最后复制的是项目里的“公开 URL”，别把后台地址发过去了。发之前拿手机打开一下，看看图片有没有丢、按钮能不能点。有登录、数据库或支付的，还得检查这些功能，页面能显示不等于都能用。
