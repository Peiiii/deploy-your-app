# 为你的应用接上 GemiGo

从一个 HTML 应用开始，接入账号、云端数据和统一点数。你决定应用的体验与收费时机，GemiGo 负责身份、确认消费和保存权益。

[开始接入](/getting-started) · [点数与权益](/points) · [运行示例](/examples)

## 先做出一个可以使用的应用

免费部分保持可用。需要跨设备保存时接入账号与 Cloud；需要收费时，在应用里选择明确的功能，再登记收费项。平台不会自动猜测关卡、道具或服务成功。

## 让 AI 帮你接入

下载 [GemiGo App Skill](/skills/gemigo-app/SKILL.md)，交给你的 AI 开发工具。Skill 包含真实 SDK 调用、收费项接入与恢复要求。部署流程使用 [GemiGo CLI Skill](/skills/gemigo-cli/SKILL.md)。

## 当前支付边界

点数余额、领取、消费、权益和受控服务使用真实后台。平台体验点无现金价值；真钱充值及作者现金结算需要完成商户与渠道开通，当前不可用。查看[钱包与收益规则](/wallet)。
