# 钱包、点数来源与作者收益

[打开我的钱包](https://gemigo.io/wallet)

## 点数从哪里来

首次登录后可主动领取一份平台体验点。同一账号只领一次，受平台总补贴预算约束，预算用完会显示原因。体验点真实进入钱包，可在不同已接入应用消费、查记录、恢复权益。

体验点没有现金价值，不兑作者现金、不支持用户间转账；它用于体验功能与验证应用接入。生产预算与每账号额度由平台配置，避免无限发点。

真钱充值目前不可用。开通条件包括经营主体、商户、统一充值跨应用消费和第三方作者结算的渠道准入，以及充值售价、费用、分成与退款规则。没有这些条件，平台不会假装生成支付成功或可提现收入。

## 收入如何归属

充值本身不计作者收入。消费绑定稳定项目与当时作者，关联原实付来源；退款恢复原批次并冲正权益和收益。作者自购不产生可结算作者收入。

在项目设置“点数与收益”查看消费与真实金额。体验消费明确显示“无现金收益”；真钱结算启用前不会提供虚假提现。

## 退款与恢复

作者可以退回尚未核销的额度或撤销一次解锁；按期权益只有没有后续购买时可直接回退。已使用服务或不确定 AI 调用需平台核查，消费者不能在前端伪造失败获得退款。

SDK 回调丢失不会丢失平台收据。刷新或换设备后，在同一账号的应用内查询权益；AI pending 查询原请求，不新建消费。
