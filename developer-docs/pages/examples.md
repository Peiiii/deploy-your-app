# 运行与修改示例

两个示例均使用正式 SDK、账号、统一钱包与点数 API。价格为体验配置，不是真钱充值售价。

## 知识实验室

[打开在线应用](https://knowledge-lab.gemigo.app) · [下载 HTML 源码](/examples/knowledge-lab.html.txt)

免费科学题；购买并核销提示；一次解锁进阶题库；购买按期练习并可选择续费；调用受控 AI 获得知识解说。登录后先打开钱包领取体验点，然后从应用按钮消费。刷新后恢复权益与原 AI 任务。

## 创意实验室

[打开在线应用](https://creative-lab.gemigo.app) · [下载 HTML 源码](/examples/creative-lab.html.txt)

免费色彩探索；一次解锁配色生成工具。与知识实验室共用同一平台钱包，各自权益隔离。

## 用 AI 改成自己的应用

下载 [App Skill](/skills/gemigo-app/SKILL.md)，向 AI 说明你的应用、免费部分和收费动作。在自己的项目创建收费项，将示例中的权益键与收费项匹配关系换成自己的配置，再通过 GemiGo 发布。

不要复用示例 appId、作者身份或收费项 ID；平台会核验当前项目来源。源码中的调用和正式 SDK 相同，浏览器本地打开不具备部署来源授权。
